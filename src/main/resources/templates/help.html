How it works

A clipboard in the browser, addressed by a short random link.

Create a paste

  1. Open the home page and type or paste your text.
  2. Pick an expiry: 1 hour, 1 day, 7 days or permanent.
  3. Optionally choose a memorable custom link of 4–64 characters.
  4. Create the link, then copy it or scan the QR code.

Good to know

  • Pastes are public to anyone who has the link. Treat the link as the password.
  • Content is rendered as Markdown with fenced code highlighting, and there is a Source view for raw code.
  • Expiry is enforced by the storage layer, so an expired paste is gone for good.
  • Request size is limited to 100000 characters and write requests are rate limited.

API

All endpoints return JSON and accept JSON except where noted.

Method and path Purpose
POST /api/pastes Create a paste. Body: {"content":"…","expiration":"1d","id":"optional"}. Expiration is one of 1h, 1d, 7d, never.
GET /api/pastes/{id} Read a paste and increment its view counter.
GET /api/pastes/{id}/qr.svg QR code for the share link, as an SVG image.
GET /actuator/health Liveness/readiness probe used by Docker Compose.

Self hosting

The easiest route is Docker Compose. Copy .env.example to .env, set a Redis password and the public base URL, then run docker compose up -d. Configuration is environment driven; see the README for the full list.

Privacy and security

No accounts, no cookies and no analytics. Server side rendering escapes all paste content; the Markdown preview runs locally in your browser and escapes raw HTML. Rate limits and content limits are configurable by the operator.
